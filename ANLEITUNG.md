# Lampe – Anleitung

## Bedienung
- **Einfach losschreiben.** Die aktuelle Zeile bleibt in der Mitte, die Lampe folgt dem Cursor.
- **Maus bewegen** (Mac) bzw. **auf den Punkt oben rechts tippen** (iPhone/iPad) → Leiste erscheint.
- **⌫-Symbol:** Löschen an/aus (Standard: aus – nur vorwärts).
- **Mond / Flamme:** Lichtfarbe wechseln (Mondlicht oder Kerze).
- **PDF sichern:** exportiert den aktuellen Eintrag. Auf dem Mac geht auch `⌘ S`.
- **Liste-Symbol:** alle Einträge, neuer Eintrag, PDF oder Löschen pro Eintrag.
- **Scrollen / Wischen:** ältere Zeilen nachlesen. Beim Weiterschreiben springt alles zurück.
- Alles wird automatisch gespeichert, nur auf dem jeweiligen Gerät.

## iCloud-Ordner anlegen (einmalig)
Dateien-App → iCloud Drive → neuer Ordner **„Tagebuch“**.

## iPhone & iPad: Kurzbefehl „Ins Tagebuch“ (einmalig, ca. 1 Minute)
1. App **Kurzbefehle** öffnen → **+**.
2. Oben auf den Namen tippen → **„Ins Tagebuch“**.
3. Unten auf **(i)** → **„Im Share-Sheet anzeigen“** einschalten → Typ nur **PDF** (bzw. „Dateien“).
4. Aktion hinzufügen: **„Datei sichern“**.
   - Ziel: **iCloud Drive › Tagebuch**
   - **„Wo sichern?“ fragen: aus**
   - **Überschreiben: an** (falls du denselben Tag nochmal exportierst)
5. Fertig. Der Kurzbefehl synchronisiert sich auch auf iPad und Mac.

**Ablauf danach:** In Lampe auf **PDF** tippen → im Teilen-Menü **„Ins Tagebuch“** → liegt in iCloud.
(Ohne Kurzbefehl geht auch: Teilen-Menü → „In Dateien sichern“ → Ordner Tagebuch.)

## MacBook
Safari → Einstellungen → Allgemein → **Speicherort für Downloads** → `iCloud Drive/Tagebuch`.
Dann landet jedes PDF direkt dort.

## Auf iPhone/iPad installieren
Seite in **Safari** öffnen → Teilen → **„Zum Home-Bildschirm“**. Dann startet Lampe wie eine App im Vollbild und funktioniert auch offline.
Für „keine Mitteilungen“: Fokus „Nicht stören“ einschalten.
